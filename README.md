# Kedai Senja

Halaman web sederhana untuk Kedai Senja yang menampilkan menu, informasi kedai,
dan cara menghubungi kami. Halaman dibuat dengan HTML, CSS, dan JavaScript tanpa
dependensi tambahan.

## Struktur file

- `index.html` berisi konten halaman dan menghubungkan stylesheet serta script.
- `eval5.css` mengatur tampilan, layout responsif, dan aksesibilitas visual.
- `script.js` menampilkan tahun otomatis dan mengarahkan tombol ke bagian menu.

## Menjalankan

Buka `index.html` di browser. Tidak diperlukan proses build atau instalasi.
